\paragraph{Port scope.}
The Pandas computation normally runs inside graph nodes through
\code{run\_code\_sandboxed\_subprocess}. C executes the unmodified sandbox program
inside its already-fresh worker. It retains upstream checks rather than claiming
unchanged dispatch plumbing. SQL invokes \code{SQLDatabaseAgent.ainvoke\_agent}
on a recreated fixture and checks both query results and database state.
Notebook persists two synthetic source collections and checks an answer for the
authorized fixture fact through its native \code{source\_chat\_graph}. It uses
the native Ollama provider, ingestion worker, and dedicated SurrealDB, whose
image digest is recorded in the manifest. Frontend behavior, embeddings, and
vector search are excluded.

\paragraph{Security denominators and observation.}
The original Pandas cohort has nine clean executions and 15 controlled-effect
executions, including the separately recorded dataset-overwrite amendment.
The later cohort has 15 clean and 15 attacked executions with fresh attempt IDs.
Its first launch batch has 30 pre-inference infrastructure failures, retained
separately. We do not count those failures as prevention or pool clean workloads.
The frozen CSV-cell attack is not retuned after its zero-attempt outcome.
Observer files lie outside worker write permissions, but the parent and arbitrary
baseline code share a host UID. The observer is not tamperproof against a
malicious parent. Model-judged quality is not used as the security oracle.

\paragraph{Additional timing statistics.}
Local-replay variances for A/B/C are 46.80, 993.96, and 1,844.46~ms$^2$.
Full-workflow variances are 1.989, 0.038, and 0.014~s$^2$, with ranges
11.986--15.293, 12.437--12.979, and 15.243--15.543~s. The paired differences
and SDs in Section~\ref{sec:evaluation} are reported from the study; paired SDs
cannot be reconstructed from marginal summaries alone. The 20-call audit
diagnostic remains separate from the 100-call replay cohort.

First-use call latencies are 283.26/525.81/949.87~ms for A/B/C. Adapter
initialization costs are 0.05/231.62/344.96~ms after 1,121.86~ms of shared imports.
Each is a single observation with uncontrolled page-cache state, not a disk-cold
estimate. Every measured C call still launches a fresh worker.

\paragraph{Reproduction records.}
The study names \path{eval/apps.csv} and \path{eval/APPLICATIONS.md} as its intake
and setup records. The scripts \path{eval/scripts/pandas_runtime.py},
\path{pandas_dispatch.py}, and \path{pandas_e2e_repetitions.py} run the replay,
dispatch checks, and model-driven repetitions. Replay parameters are
\code{--warmup 10 --samples 100}; the audit diagnostic uses two warm-ups and
20 samples. Commands use the pinned upstream environment and fresh output paths.
The reports \path{macro-metrics.json} and \path{application-pilot.md} identify
derived statistics, controlled effects, and the oracle correction. The result
directories distinguish the runtime, audit-profile, dispatch, failed-launch,
and retry cohorts. These records and the exact implementation overlay must
accompany the anonymous artifact; a source commit by itself cannot reproduce
the application study.
